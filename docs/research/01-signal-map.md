## 三个金矿（PRD 未提）

### 金矿①：政府采购/招投标——数字化预算的公开账本
《XX市教育局智慧教育平台建设项目招标公告》，预算 286 万元，需求含「AI 学情分析、知识库问答」，投标截止 8 月 20 日。**全网唯一带公开预算和 deadline 的需求库**，个人可直投小额标的（<100 万）。
渠道：中国政府采购网（官方接口，2024 起，需数字签名 + HTTPS）、省级公共资源交易中心、剑鱼标讯（开放接口 + 微信推送）。
筛法：「AI/知识库/小程序/数据治理」+ 本省 + 预算 20~200 万。｜高｜P0

### 金矿②：应用商店差评——最诚实的痛点
渠道：App Store 官方评论源（免鉴权，按店铺分，单应用约 500 条）、Google Play 评论、七麦「用户评价追踪」、G2。
例：某 AI 笔记 App 近 30 天差评中「导出要付费」「中文排版乱」各 40+ 次 → 做导出工具或中文平替。
抓法：锁 20 个竞品每日拉差评聚类。｜高｜P1

### 金矿③：Acquire.com/Flippa——已验证模式 + 价格基准
listing 明写 MRR、获客渠道、售价倍数，是免费的「什么生意赚钱、值多少钱」样本库，可做选品定价基准，也能服务卖家。
渠道：Acquire.com（SaaS 为主，详情需订阅）、Flippa（上架费 $29–$499）、Tiny Acquisitions。
例：「Chrome 插件，MRR $3.2k，售价 $85k（2.2× 年收入），靠 SEO 获客」→ 国内空白且打法可复制。
抓法：新上架 listing 邮件/RSS 提醒；建「类目—收入—倍数」基准表。｜高｜P1

## 只能监控 5 个，选哪 5 个

1. **V2EX「酷工作」+ 电鸭**——唯一能直接成交的信号，零成本
2. **政府采购网/剑鱼标讯**——唯一带预算和 deadline 的公开需求库，竞争小于互联网外包
3. **App Store 官方评论源**——痛点最诚实、可程序化、可跨竞品横比，直接产出选题
4. **招聘 JD（BOSS 人工录入）**——技术预算先行指标，反推外包缺口；录入解决合规
5. **IT桔子融资接口**——拿钱公司 3 月内产生采购与外包，是前几类的上游线索源

> 理由：前两个直接变现，第三个变产品，第四五个供给「谁有钱、谁缺人」的上游线索。

## 已核对的事实支撑

- 中国政府采购网确有官方数据接口（2024 起，需数字签名 + HTTPS）；剑鱼标讯有开放接口与微信推送可绕开自建签名
- App Store 评论有免鉴权官方 JSON 源（按店铺分、单应用上限约 500 条）
- OSS Insight 提供免鉴权趋势接口（约 600 req/h），可替代无官方 API 的 GitHub Trending
- 禁爬平台（BOSS/闲鱼/小红书/猪八戒）一律人工录入，符合合规红线
