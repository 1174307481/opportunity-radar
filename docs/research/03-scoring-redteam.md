# 研究 03：评分体系红队报告

> 研究轮次：产品设计 V2 · 2026-09-11 · agent: zfg-C
> 方法：构造 20 条典型信息，按 V1 八维度权重实际推演打分，暴露失效模式后重设计。

## 一、模拟测试结果（摘要）

打分公式：score = Σ(维度分 × 权重/100)。权重：需求强度20 / 付费意愿15 / 信息差15 / 利润空间15 / 技术匹配15 / 执行难度10 / 竞争5 / 新鲜度5。

代表性样本与得分：

| # | 信息摘要 | 类型 | 总分 |
| --- | --- | --- | --- |
| 16 | IH 帖「AI 做商品图月入 $8k」 | 效差 | 78.5 |
| 1 | **外包帖：AI 知识库系统，预算 3-5 万（真实买家）** | 接单 | 76.3 |
| 15 | PH 热门 AI 落地页工具 $29/月 | 信差 | 75.0 |
| 7 | GitHub 开源 AI 客服系统 12k stars（无直接买家） | 资差 | 69.3 |
| 2 | 外包帖：小程序商城改版 8 千（真实买家） | 接单 | 68.3 |
| 10 | 干货：RAG 优化 7 个技巧（纯学习噪音） | 噪音 | 51.3 |
| 20 | 3 年前博客「AI 做 SEO 月入 $5k」（常青有效） | 效差 | 56.3 |
| 13 | 水军：AI 币暴涨 300% | 噪音 | 28.8 |

## 二、暴露的 5 个失效模式

1. **分数挤在 60~80，无区分度。** 20 条里 12 条落在 60~79。69 分和 60 分用户无法判断差多远；#8 和 #9 完全同分(62.8)，一个是开源项目一个是 SaaS 涨价——连续分制造虚假精确感
2. **真实接单帖被竞争维度压低。** 预算 3-5 万的真实外包帖（76.3）排在别人的成功故事（78.5）之后；8 千小程序真实买家（68.3）低于无直接买家的开源项目（69.3）。有真实买家的机会永远高于「可能可以复刻」的机会，不该被加权平均掉
3. **新鲜度惩罚常青内容。** 3 年前文章所述商业模式至今有效，被新鲜度 10 分拖到 56 分埋掉
4. **学习权重 ±10 形同虚设。** 冷启动全为 0；即便用一周，收藏 AI Agent 标签只 +0.6，远不够翻转排序。且真实信号在机会类型级别（用户收藏的是「接单类」），不在 tag 级别
5. **技术匹配度抬高噪音。** RAG/LangGraph 教程技配 90+，贡献 13.5+ 分被推到 50+，看起来像「可以关注」

## 三、重设计回答

- **a) 排序还是过滤？过滤更重要。** 每天看 5~20 条，核心决策是「今天看还是不看」。78 和 76 的差距在 LLM 打分误差以内；过滤是二值决策，比排序诚实
- **b) 信号类型优先于数字分？成立。** 接单类的本质信号「此刻有人花钱解决问题」比任何加权平均都强。接单类只要需求方真实+有预算，直接进今日必看，跳过数字排序
- **c) 档位化比连续分诚实？是。** LLM 分不清 76 和 78，但分得清「该今天看」和「该归档」。3 档：今天看/本周看/归档
- **d) 校准手段选「先分类后打分」。** 分类是 LLM 高可靠任务，打分是低可靠任务；先定类型，再在该类型语境下打分——接单天然不打信息差分，产品天然不打付费意愿分。锚点示例治标不治本；相对比较需批处理不适用逐条流水线
- **e) 每分必带理由——硬规则。** 理由比分数有价值：分数说「多少分」，理由说「该不该信」。无理由的分数=黑箱；说不出理由→降一档

## 四、砍单判决

| 维度/机制 | V1 处置 | 一句理由 |
| --- | --- | --- |
| 需求强度(20) | 保留，前置为分类信号 | 最强信号，应前置为分类判定而非打分 |
| 付费意愿(15) | 并入「需求真实性」 | 与需求强度高度耦合，分开打=重复计权 |
| 信息差(15) | 降为 5（独特性） | 仅对信差类有意义 |
| 利润空间(15) | 降为 5 | LLM 预估利润太不准 |
| 技术匹配度(15) | **改为过滤器** | <40 直接归档，二值过滤比 15% 权重有效 |
| 执行难度(10) | 降为 5 | 有价值但非主信号 |
| 竞争程度(5) | **砍掉** | 真实接单不该被竞争压低（失效 2 根因） |
| 信息新鲜度(5) | **砍掉**，改为档内排序因子 | 不该参与评分（失效 3 根因），但可用于同档排序 |
| 学习权重(±10) | 降为搜索加权 | 冷启动=0，tag 粒度太细（失效 4 根因） |
| 用户改分 | 保留，**改为改档位** | 「这条进今天看」比改 78→85 诚实 |

## 五、重设计方案

**阶段一：分类路由（L1）**——判定信号类型（接单/信差/价差/效差/资差/产品/噪音）。接单类触发快通道：只要需求方真实+有预算 → 自动进「今天看」。噪音 → 归档。其余 → 阶段二。

**阶段二：四维度打分（L2）**

| 维度 | 权重 | 口径 |
| --- | --- | --- |
| 需求真实性 | 40 | 需求方+预算+时间窗=90+；有需求方无预算=50~70；仅推测≤40 |
| 行动可行性 | 30 | 技配≥60%+交付≤1月+利润为正=80+；任一不满足逐降 |
| 独特性 | 15 | 国内无同类=80+；有竞品可差异化=50~70 |
| 时效性 | 15 | 有 deadline=90+；**常青内容=70（不被旧惩罚）**；过时≤30 |

Skill Match < 40 → 直接归档，不进入打分。学习权重 V1 降为搜索/同档排序加权。

**三档呈现**：🔴 今天看（接单快通道 或 总分≥70）｜🟡 本周看（40~69）｜⚪ 归档（<40 或 技配<40 或 噪音）

**强制理由**：每条分数旁必须展示「为什么是这个分：[一句话，引用原文证据]」。说不出的 → 降一档。

**解决了**：挤 60~80（快通道+权重集中）、接单被压低（快通道+砍竞争维度）、常青被埋（时效性 70 分）、学习权重虚设（降级）、技配抬噪音（改过滤器）。
